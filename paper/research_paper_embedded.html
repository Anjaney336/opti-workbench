Current Engine Scope

The live system combines a Black-Litterman return engine, covariance conditioning, regime-aware scenario construction, exact empirical-CVaR QP seeding, warm-started PSO refinement, warm-started GA refinement, and an adaptive hybrid selector. The objective is multi-term and includes covariance risk, return reward, liquidity reward, transaction cost, empirical CVaR, diversification-gap control, concentration penalty, regime stress, tracking penalty, and an entropy-style diversification bonus.

What Changed From the Old Paper

  • The paper no longer describes the optimizer as a plain mean-variance toy study.
  • The return engine is now documented as Black-Litterman with Bayesian-smoothed views.
  • The QP stage is now described correctly as an exact empirical-CVaR seed with optional discrete subset screening.
  • The hybrid stage is now described correctly as a selector over QP, PSO, GA, and BLEND, not just a fixed averaged blend.
  • The conclusions were rewritten to avoid unsupported claims of universal optimizer superiority.
